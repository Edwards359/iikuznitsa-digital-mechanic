# Каталог `data/` — не в Git

<!-- markdownlint-disable MD013 -->

PDF руководств производителей и текстовый RAG-индекс **не публикуются** в открытом репозитории (требование организаторов и авторские права).

## Что положить локально или на стенд

| Путь | Содержимое |
| --- | --- |
| `manuals/` | Шесть PDF из материалов задачи (кабинет хакатона), имена — в `app/manuals.py` |
| `index/` | Результат `python -m app.rag` (и опционально `--ocr`) |
| `app.db` | SQLite заявок и консультаций (создаётся при работе) |
| `journal.jsonl` | Журнал шагов агента (создаётся при работе) |

Скачивание архива материалов — из личного кабинета; URL можно хранить в переменной окружения (см. `HACKATHON_MATERIALS_URL` в `.env.example`), **не** в коде с секретами.

## Сборка индекса

```text
python -m app.rag --ocr
```

Подробно: [docs/SEARCH-RAG.md](../docs/SEARCH-RAG.md), синхронизация на VPS: [deploy/DATA-SYNC.md](../deploy/DATA-SYNC.md).

## Проверка

Убедитесь, что в Git нет PDF и `index/`:

```text
git ls-files data
```

Должен быть пустой вывод (достаточно этого файла в исключении из `.gitignore`).
