# Эксплуатация: замер YandexGPT Pro 5 (биллинг Cloud)

<!-- markdownlint-disable MD013 -->

Источник: выгрузка детализации расходов Yandex Cloud
`20261028-20261128.csv` (экспорт 2026-11-28). Учётная запись стенда хакатона.

## Тариф (подтверждён выгрузкой)

| SKU YandexGPT Pro 5 (синхронный режим) | Единица | ₽ / ед. |
| --- | --- | ---: |
| Входящие токены | 1k·token | **1,20** |
| Исходящие токены | 1k·token | **1,20** |
| Кешированные токены | 1k·token | **1,20** |

Ставка **одинаковая** для входа, выхода и кэша. В приложении
`YANDEX_RUB_PER_KTOK=1.20`; оценка `cost_rub` =
`(input_tokens + output_tokens) × 1,20 / 1000` по полям usage API
(`inputTextTokens` + `completionTokens`). Токены кэша в usage API
отдельно не приходят — в журнале консультаций кэш **не** учтён;
в реальном счёте Cloud он есть (см. ниже).

| SpeechKit | Единица | ₽ / ед. |
| --- | --- | ---: |
| Синхронное распознавание речи | 15·секунд | **0,1626** |

На стенде демо: `VOICE_MODE=browser` → **0 ₽** SpeechKit.
SpeechKit включается только при `VOICE_MODE=yandex`.

## Калькулятор кабинета и парк

Шаблон организаторов: цена **1200 ₽ / 1 млн токенов** (= 1,20 ₽ / 1k)
на вход и выход — совпадает с биллингом. Итог сценария в заполненном
xlsx: **≈3,72 ₽** на консультацию по замерам usage (без строки кэша
в шаблоне). Парк-иллюстрация: 250 конс/мес → **≈930 ₽/мес LLM**.

Если нужно сблизить оценку со счётом Cloud при активном кэше —
добавлять к токенам входа сопоставимый объём cached (на стенде
кэш ≈ вход) или смотреть консоль биллинга.

В приложении:

- каждый `/api/consult` → SQLite `consultations`, поле `cost_rub`;
- сводка: `GET /api/usage/summary`, по машине —
  `GET /api/vehicles/{vehicle_id}`.

Инфраструктура: VPS (фикс) + трафик; деплой — `deploy/README.md`.
SpeechKit roadmap — [VOICE-ROADMAP.md](VOICE-ROADMAP.md).
