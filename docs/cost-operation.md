# Эксплуатация: замер YandexGPT Pro 5 (2026-11-26)

Фактический биллинг Yandex AI Studio за день отладки стенда (одна учётная запись):

| Статья | Объём (1k·token) | Сумма, ₽ |
| --- | --- | --- |
| Кэш (cached) | 71,33 | 85,59 |
| Вход (incoming) | 65,11 | 78,14 |
| Выход (outgoing) | 10,01 | 12,02 |
| **Итого за день** | **≈146** | **≈175,75** |

Смешанная ставка: **≈1,20 ₽ за 1000 токенов** (вход+выход; кэш у Yandex тарифицируется отдельно, в приложении в `usage` пока суммарные токены).

В приложении:

- каждый вызов `/api/consult` пишет строку в SQLite (`consultations`);
- поле `cost_rub` считается как `(input_tokens + output_tokens) × YANDEX_RUB_PER_KTOK / 1000` (по умолчанию `1.20`);
- сводка по всем консультациям: `GET /api/usage/summary`, по машине — в `GET /api/vehicles/{vehicle_id}`.

Иллюстрация для сдачи (не месячный прогноз): при **12k токенов на консультацию** → **≈14,4 ₽**; 300 консультаций в месяц → **≈4 320 ₽** только LLM (без VPS и SpeechKit).

SpeechKit STT тарифицируется отдельно в Yandex Cloud; короткие голосовые команды (~3 с) дают доли копейки за срабатывание.

Инфраструктура стенда: VPS (фиксированная аренда) + трафик; при деплое через Docker см. `deploy/README.md`.
