# Голосовое управление пошаговым ремонтом

<!-- markdownlint-disable MD013 -->

## Что нужно заказчику

Hands-free (или почти) навигация по шагам: «**Помощник**, следующий шаг», «назад», «шаг 3». Кодовое слово отсекает шум цеха.

## Режим по умолчанию: `VOICE_MODE=browser` (0 ₽ для нас)

- **Web Speech API** в Chrome / Edge на **HTTPS**: распознавание на стороне браузера, счётчика Yandex не крутим.
- Кнопка «Включить голосовые команды» → непрерывное слушание с перезапуском `onend`.
- Дублирование: **← →** и кнопки на экране.

Ограничение: иногда `error: network` (облако Google недоступно с сети пользователя). Тогда — клавиши или второй режим.

## Резерв: `VOICE_MODE=yandex` (платно, осознанно)

- Только **push-to-talk**: удержали кнопку → **один** запрос SpeechKit (~4,5 с), **без** фонового цикла каждые 3 с.
- Нужны `YANDEX_API_KEY` и `VOICE_MODE=yandex` (или устаревший `VOICE_STT_ENABLED=1` без `VOICE_MODE`).
- Для демо на VPS по умолчанию **не** включаем.

## Дальше (если Web Speech мало)

1. **Vosk / whisper.cpp** на VPS, словарь 10 фраз — фиксированная CPU-нагрузка, без поминутного биллинга.
2. **PWA на Android** — системный бесплатный STT.
3. SpeechKit только как fallback по `VOICE_MODE=yandex` + push-to-talk.

Переменные: `VOICE_MODE` = `browser` | `yandex` | `off`.
