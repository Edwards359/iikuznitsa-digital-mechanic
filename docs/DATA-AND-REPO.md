# Данные задачи и открытый репозиторий

<!-- markdownlint-disable MD013 -->

По разъяснениям организаторов (27.11.2026):

## Не коммитить

- PDF заводских руководств по ремонту;
- текстовые RAG-индексы (`pages.jsonl`, `chunks.jsonl`, `embeddings.npz` и аналоги);
- ключи и `.env` (только `.env.example` без значений);
- журналы с персональными или коммерческими данными.

Если файл уже попал в историю — **удалить следующим коммитом**, историю **не переписывать**.

## Можно в публичном репозитории

- код агента, поиска, API, UI;
- архитектура и инструкции запуска;
- заглушки заказчика `vendor/mock` (JSON машин и кодов);
- подключение базы знаний через `MANUALS_DIR`, `INDEX_DIR`, сборка индекса на стенде.

## Стенд

Материалы задачи разворачиваются на сервере с ограниченным доступом (у нас — VPS). Код на GitHub — без содержимого руководств.

## Самостоятельный запуск жюри

Организаторы **не** обязаны поднимать продукт из репозитория; оценивают код и стенд по URL.
